 Railway Management System (DBMS Mini Project)

A complete web-based Railway Ticketing System built with Python, Flask, and MySQL. This project mimics the official IRCTC portal, allowing users to search for trains, view real-time schedules, book tickets, and simulate payments securely. 

Tech Stack
* Frontend: HTML5, CSS3, Bootstrap 5, JavaScript
* Backend: Python 3 (Flask)
* Database: MySQL

Key Features
* Real-World Data: 200+ South Indian railway stations and 100+ active train routes.
* Smart Train Search: IRCTC-themed UI with dynamic Train Cards.
* Secure Payment Simulation: Interactive payment gateway simulating UPI (QR Code) and Card processing.
* Ticket Management: Automated seat allocation and secure cancellation features.

How to Run Locally
1. Clone this repository.
2. Import the `database.sql` file into phpMyAdmin (Database name: `railway_db`).
3. Install dependencies: `pip install Flask mysql-connector-python`
4. Run the app: `python app.py`
